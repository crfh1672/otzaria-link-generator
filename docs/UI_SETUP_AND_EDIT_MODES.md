## 1. ארכיטקטורת תזרימי העבודה בממשק

אפליקציית מחולל הקישורים פועלת במודל של **מצב כפול (Two-Phase Mode System)**, המבטיח הפרדה ברורה בין שלב הקלט וההגדרות לשלב העריכה, הבקרה והייצוא.

```
                  ┌─────────────────────────────────┐
                  │      מסך ההגדרות (Setup Mode)   │
                  │ - הזנת/טעינת טקסט               │
                  │ - קביעת פרמטרים וסינונים        │
                  │ - הרצת מנוע הניתוח והזיהוי     │
                  └────────────────┬────────────────┘
                                   │
                         [סיום הניתוח והפקת קישורים]
                                   │
                                   ▼
                  ┌─────────────────────────────────┐
                  │      מסך העריכה (Edit Mode)    │
                  │ - סקירת קישורים וקוד צבעוני     │
                  │ - בחירת מועמדים חלופיים          │
                  │ - תצוגה מקדימה של מקור אוצריא    │
                  │ - אישור גורף / ייצוא קבצים       │
                  └─────────────────────────────────┘
```

## 2. מסך הבחירה וההגדרות (Setup Mode) - תיעוד מלא

מסך ה-Setup מיועד להכנת המסמך לניתוח, הקלטת הפרמטרים הנדרשים, קביעת רמת הקפדנות של האלגוריתם, ובחירת היקף הספרים המבוקש.

### 2.1 מנגנוני הזנת קלט וטעינת טקסט
המערכת מציעה שלוש דרכים שונות להזנת הטקסט התורני:

1. **הקלדה / הדבקה ישירה (Direct Text Editor)**:
   * תיבת טקסט רב-שורתית כתומה/ניטרלית בעיצוב מודרני עם תמיכה מלאה ב-RTL (ימין לשמאל).
   * מונה תווים ומילים בזמן אמת.
   * כפתור ניקוי מהיר (`מחק טקסט`).

2. **טעינת קובץ בגרור-והשלך (Drag & Drop File Upload)**:
   * אזור ייעודי התומך בגרירת קובצי טקסט (`.txt`, `.markdown`, `.md`, `.json`, `.html`).
   * קריאת קובץ מקומית מיידית ללא צורך בהעלאה לשרת חיצוני (Client-Side HTML5 FileReader API).

3. **בחירת טקסט לדוגמה מובנה (Sample Text Selector)**:
   * כפתורי טעינה מהירה של קטעי טקסט תורניים מגוונים לבדיקה מיידית:
     * **סוגיית גמרא ומפרשים** (ברכות, דף ב' - כולל רש"י ותוספות).
     * **קטע הלכתי משולחן ערוך** (אורח חיים - הלכות נטילת ידיים).
     * **קטע מתוך משנה תורה לרמב"ם** (הלכות יסודי התורה).
     * **תשובה שו"ת תורנית מורכבת** (הכוללת מגוון רחב של מראות מקומות משולבים).

---

### 2.2 לוח כיוונון הפרמטרים של האלגוריתם
לוח הפרמטרים מאפשר לשלוט בדיוק ובגמישות מנוע הזיהוי:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        פרמטרי ניתוח ואלגוריתם                         │
├────────────────────────────────────────────────────────────────────────┤
│ סף ניקוד מינימלי: [========|====] 70%                                   │
│ כמות מועמדים מקסימלית: [3]                                             │
│ [X] הפעל חיפוש גמיש (Fuzzy Matching)                                   │
│ [X] הרחבת ראשי תיבות אוטומטית                                          │
│                                                                        │
│ היקף ספרים לסינון:                                                     │
│ (V) ש"ס בבלי  (V) שולחן ערוך  (V) רמב"ם  (V) מקרא  ( ) ירושלמי        │
└────────────────────────────────────────────────────────────────────────┘
```

1. **סלידר סף ניקוד מינימלי (Minimum Confidence Score Threshold)**:
   * קובע את ציון הסף (בטווח 0% עד 100%, ברירת מחדל: **70%**).
   * ציטוטים שיקבלו ציון נמוך מהסף יסומנו כ-`unresolved` (אדום) או שיירדו מתוצאות ההמלצה.

2. **כמות מועמדים מקסימלית לכל ציטוט (Max Candidates per Citation)**:
   * הגדרה של מספר ההצעות החלופיות שיישמרו עבור כל ציטוט (בין 1 ל-5 מועמדים, ברירת מחדל: **3**).

3. **מתג חיפוש גמיש (Fuzzy Search Toggle)**:
   * הפעלה או כיבוי של אלגוריתם דמיון מילים (Levenshtein/Jaro-Winkler). כשהוא פעיל, המערכת מזהה גם שגיאות הקלדה ושינויי כתיב חסר/מלא.

4. **מתג הרחבת ראשי תיבות אוטומטית (Abbreviation Expansion Toggle)**:
   * הפעלה או כיבוי של המילון התורני. כשהוא פעיל, המערכת ממירה קיצורים (כגון `שו"ע`, `תוס'`) לצורתם המלאה בעת סריקת המועמדים.

5. **סינון היקף ספרים (Book Category Filter Selectors)**:
   * אפשרות למקד את החיפוש בקטגוריות ספרים מסוימות בלבד:
     * **תנ"ך ומקרא**
     * **תלמוד בבלי וש"ס**
     * **תלמוד ירושלמי**
     * **משנה תורה לרמב"ם**
     * **טור ושולחן ערוך**
     * **נושאי כלים ומפרשים**

---

### 2.3 בחירת מצב חיבור למאגר אוצריא
המערכת תומכת בשני מצבי עבודה מול ספריית אוצריא:

1. **מצב סימולציה / הדגמה (Mock Library Mode)**:
   * עבודה עצמאית עם אינדקס מובנה של ספריית אוצריא. אינו דורש התקנה פתוחה של אפליקציית אוצריא ברקע.
2. **מצב גשר חי (Live Otzaria Bridge Mode - SDK v1.x)**:
   * תקשורת בזמן אמת מול אפליקציית אוצריא דרך ממשק ה-API/Plugin SDK. מאפשר חיפוש חי במאגר הספרים המלא של המשתמש ופתיחה ישירה של הספרים באפליקציה.

---

### 2.4 מנגנון הרצת הניתוח, מד ההתקדמות ויומן הסטטיסטיקות
בעת לחיצה על כפתור **"התחל ניתוח וזיהוי קישורים"**:

1. **מד התקדמות שלבי (Multi-Step Progress Indicator)**:
   * **שלב 1**: נרמול טקסט והרחבת ראשי תיבות.
   * **שלב 2**: סריקת אסימונים וזיהוי תבניות ציטוט.
   * **שלב 3**: חיפוש במאגר אוצריא וחישוב ציוני התאמה.
   * **שלב 4**: עיבוד תוצאות ומעבר למסך העריכה.

2. **יומן סטטיסטיקות בסיום הניתוח**:
   * **סה"כ ציטוטים שנמצאו**.
   * **קישורים בוודאות גבוהה** (ירוק).
   * **ציטוטים המצריכים הכרעה** (צהוב).
   * **ציטוטים ללא התאמה מספקת** (אדום).
   * **זמן עיבוד כולל (במילישניות)**.

---

### 2.5 חלונות מודאליים וכלים נלווים ב-Setup Mode

#### 1. חלון מילון ראשי תיבות (`AbbreviationsModal.tsx`)
* צפייה בכל 400+ הערכים במילון.
* אפשרות לחיפוש, הוספת קישור מותאם אישית חדש, עריכה או מחיקה.

#### 2. חלון ניהול פרויקטים (`ProjectsModal.tsx`)
* שמירת המסמך וההגדרות הנוכחיות כפרויקט שמור בדפדפן (LocalStorage/IndexedDB).
* טעינת פרויקטים קודמים, ייבוא וייצוא קובצי פרויקט בפורמט `.json`.

#### 3. חלון מקמפל ומייצא התוסף (`SingleHtmlExporterModal.tsx`)
* **ייצוא חבילת `.otzplugin`**: יצירת קובץ ZIP תקני הכולל את `manifest.json` ו-`index.html` מוכן להתקנה ישירה באוצריא.
* **ייצוא קובץ HTML בודד (Single HTML Bundle)**: הפקת קובץ עצמאי שרץ בכל דפדפן ללא תלויות.

## 3. מסך העריכה והבקרה (Edit Mode) - תיעוד מלא

לאחר סיום הניתוח, המערכת עוברת למסך העריכה. מסך זה מספק סביבת עבודה אינטראקטיבית מלאה לבדיקת הקישורים, הכרעה בציטוטים מסופקים, צפייה בטקסט המקור מתוך אוצריא, וייצוא.

### 3.1 מבנה תצוגה מפוצלת (Dual-Pane Split Layout)

```
┌───────────────────────────────────────────────────┬────────────────────────────────────────┐
│             פנל עורך המסמך והציטוטים               │       פנל מפקח הקישור ותצוגה מקדימה    │
│                 (צד ימין - 65%)                   │            (צד שמאל - 35%)             │
├───────────────────────────────────────────────────┼────────────────────────────────────────┤
│ סרגל סינון: [הכל] [מאושרים] [לביקורת] [מבוטלים]  │ 📖 תצוגה מקדימה - אוצריא               │
│                                                   │ ספר: בבלי ברכות (דף ב עמוד א)           │
│ "תנן התם: מאימתי קוראין את שמע בערבית?            │ -------------------------------------- │
│  מאימת [ברכות דף ב ע"א - V] הכהנים נכנסים..."     │ "מאימתי קוראין את שמע בערבית, משעה      │
│                                                   │  שהכהנים נכנסים לאכול בתרומתן..."      │
│ ┌───────────────────────────────────────────────┐ │                                        │
│ │ כרטיס קישור: ברכות דף ב ע"א (ציון: 98%)        │ │ [פתחי ספר באוצריא]                     │
│ │ מועמד נבחר: [ בבלי ברכות - דף ב. (ע"א)  v ]     │ │ [אישור קישור] [החלף מועמד]             │
│ └───────────────────────────────────────────────┘ │                                        │
└───────────────────────────────────────────────────┴────────────────────────────────────────┘
```

### 3.2 מערכת הסטטוסים והקוד הצבעוני של הציטוטים

כל ציטוט שזוהה במסמך מקבל מסגרת ורקע צבעוני בהתאם לרמת הוודאות והסטטוס שלו:

| סטטוס | צבע ויזואלי | משמעות תפעולית | תנאי סף |
| :--- | :--- | :--- | :--- |
| **מאושר (Confirmed)** | 🟢 **ירוק** | קישור מאושר ובטוח. יכלל בייצוא הסופי. | ציון $\ge 85\%$ או אישור ידני |
| **דורש הכרעה (Ambiguous)** | 🟡 **צהוב** | נמצאו מספר מועמדים בעלי ציון קרוב. מומלץ לבחור מועמד לבד. | $65\% \le \text{ציון} < 85\%$ |
| **לא נמצא (Unresolved)** | 🔴 **אדום** | ציטוט שזוהה בטקסט אך לא נמצאה עבורו התאמה בטוחה במאגר. | ציון $< 65\%$ |
| **מבוטל (Rejected)** | ⚪ / 🔘 **אפור** | קישור שבוטל על ידי המשתמש (נדחה). לא יופיע כהיפר-קישור בייצוא. | ביטול ידני |

---

### 3.3 כרטיס הקישור האינטראקטיבי ובוחר המועמדים

בלחיצה על ציטוט מודגש במסמך, נפתח **כרטיס קישור אינטראקטיבי (Link Card)** המציג:

1. **הטקסט המקורי שזוהה במסמך**: הטקסט המדויק כפי שהוקלד.
2. **פרטי הספר והמיקום שנמצאו**: שם הספר, הפרק, הדף, העמוד או הסימן.
3. **ציון ההתאמה המשוקלל (Score Breakdown)**:
   * בלחיצה על כפתור הציון נפתח חלון קטן המציג את פירוק הניקוד (ציון בסיס, בונוס גימטריה, בונוס ספר, קנס מילים שכיחות).
4. **תפריט נפתח לבחירת מועמד חלופי (Candidate Selector Dropdown)**:
   * במידה והאלגוריתם מצא מספר ספרים או מיקומים אפשריים, המשתמש יכול לעבור בין המועמדים בלחיצת עכבר אחת.
5. **שדה עקיפה וחיפוש ידני (Manual Override Search)**:
   * אפשרות להקליד ידנית שם ספר ומיקום ולחפש ישירות באינדקס אוצריא במידה והאלגוריתם לא מצא את המקור המבוקש.
6. **כפתורי פעולה מהירה בכרטיס**:
   * **אישור קישור (Confirm)**: מעביר לסטטוס ירוק.
   * **דחייה / ביטול קישור (Reject)**: מעביר לסטטוס אפור.
   * **עריכת פרטי הקישור (Edit Link Modal)**: פותח דיאלוג עריכה מתקדם (`EditLinkModal.tsx`).
   * **צפייה במקור באוצריא (View Source)**: טוען את קטע הספר בפנל התצוגה המקדימה.

---

### 3.4 סרגל סינון ופעולות אצוותיות

בראש מסך העריכה ממוקם סרגל כללים מתקדם לניהול מהיר של כל הציטוטים במסמך:

1. **כפתורי סינון לפי סטטוס**:
   * `הכל (All)` - הצגת כל הציטוטים.
   * `מאושרים (Confirmed)` - הצגת הציטוטים הירוקים בלבד.
   * `לביקורת (Needs Review)` - הצגת הציטוטים הצהובים והאדומים.
   * `מבוטלים (Rejected)` - הצגת הציטוטים המבוטלים.

2. **פעולות אצוותיות גורפות (Batch Tools)**:
   * **אישור גורף לכל הציטוטים בוודאות גבוהה (`Approve High Confidence`)**: מאשר בלחיצה אחת את כל הציטוטים שקיבלו ציון מעל 80%.
   * **דחייה גורפת לכל הציטוטים הבלתי פתורים (`Reject Unresolved`)**: מוחק/מבטל את כל הציטוטים האדומים.
   * **איפוס כל הקישורים (`Reset All`)**: מחזיר את כל הציטוטים למצב הראשוני שלאחר הניתוח.

### 3.5 פנל תצוגה מקדימה וצפייה בטקסט המקור באוצריא
הפנל השמאלי במסך העריכה משמש כחלון תצוגה מקדימה המציג את הטקסט מתוך ספר אוצריא:
* הצגת כותרת הספר והמיקום (לדוגמה: **ספר בבלי ברכות, דף ב' עמוד א'**).
* הצגת קטע הטקסט המלא מתוך המאגר עם **הדגשה חזותית של דיבור המתחיל (ד"ה)** או המשפט המצוטט.
* כפתור **"פתח ספר באוצריא"** לפתיחת התוסף/הספר ישירות באפליקציית אוצריא הראשית.

### 3.6 מערכת הייצוא הרב-פורמטי

מסך העריכה כולל מנוע ייצוא עשיר המאפשר להוריד או להעתיק את המסמך המעובד במגוון פורמטים:

1. **ייצוא Markdown היפר-טקסטואלי (`.md`)**:
   * המרת הציטוטים המאושרים לקישורי Markdown תקניים:
     `[ברכות דף ב ע"א](otzaria://book/בבלי%20ברכות/page/2)`
2. **ייצוא קובץ HTML עשיר (`.html`)**:
   * הפקת קובץ HTML שבו הציטוטים מוצגים כהיפר-קישורים צבעוניים עם אפשרות ללחיצה ופתיחה.
3. **ייצוא קובץ `links.json` ייעודי לאוצריא**:
   * הפקת קובץ נתונים מבני בפורמט התוספים של אוצריא, המכיל מפות קישורים מדויקות בין תווי המסמך לבין מזהי ספרים ומיקומים.
4. **ייצוא קובץ פרויקט JSON מלא (`.json`)**:
   * שמירת כל מצב העבודה כולל הטקסט, ההגדרות, הציטוטים וההכרעות הידניות לטעינה עתידית.
5. **העתקת טקסט נקי / טקסט מעובד ללוח (Copy to Clipboard)**.

## 4. נגישות, עיצוב ותמיכה בערכות נושא

* **עיצוב תורני נקי (Otzaria Design System)**: שימוש בטיפוגרפיה ברורה, מרווחי פדינג נדיבים, והפרדה חזותית נקייה ללא עומס מיותר.
* **ערכת נושא דינמית (Dark / Light Theme)**: תמיכה מלאה במצב כהה (Dark Mode) ומצב אור (Light Mode) המותאמים אישית לקריאה ממושכת של טקסטים תורניים.
* **תמיכה מלאה ב-RTL ובמקלדת**: ניווט מלא בעזרת מקלדת (Tab, Enter, Escape) ומעבר מהיר בין ציטוטים.
